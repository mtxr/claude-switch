# claude-switch

## Language

Everything written into this repository MUST be in English, regardless of the language used in the conversation:

- Source code: identifiers, comments, doc comments, string literals, CLI output and error messages
- Tests: test names, fixtures and assertion messages
- Docs: README, CHANGELOG and any other markdown
- CI, scripts and workflow files
- Commit messages, PR titles and PR descriptions

Chat with the user in whatever language they use; only the repo output is English. Never leave Portuguese (or any other language) in committed files.
